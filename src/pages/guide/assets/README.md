# Guide screenshots

The guide works without screenshots. Add PNG files here using the names below; Vite picks them up automatically on the next build. Missing files render no image or placeholder. No code change is needed

| File                | Capture                                                       | Section                          |
| ------------------- | ------------------------------------------------------------- | -------------------------------- |
| `week-overview.png` | A week with 3–4 example tasks and a few different daily marks | Your week at a glance            |
| `add-task.png`      | The task input and a newly added task                         | Start with a few tasks           |
| `choose-status.png` | A day cell with its status menu open                          | Give each day a mark             |
| `next-week.png`     | A task menu with Copy to next week visible                    | Make room for next week          |
| `habit-example.png` | Read for 20 minutes with marks on several days                | Keep habits alongside your tasks |

Use demonstration data rather than personal account data. Keep the same week and task names throughout: Prepare a presentation, Book a dentist appointment, Sort out paperwork, and Read for 20 minutes

Capture at a consistent browser zoom and crop to the relevant controls. Export at 1440 × 900 where practical; other image sizes are displayed at their natural aspect ratio. Check that labels are readable on a phone. Include the current English menu labels exactly as they appear in the application

Alt text and captions live in `../ui/guide-page.tsx`. Update them if the supplied images show a different example
